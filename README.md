# IT Toolkit

Practical PowerShell and Windows scripts for real-world IT problems.
Each script lives in its own folder, with a README explaining what it does and how to use it.

## Scripts

| Script | What it does | Platform |
|---|---|---|
| [SecureBrowser](./SecureBrowser) | Password-protect browser data (Chrome, Edge, Firefox, Brave) on a shared Windows account | Windows 10/11 |

## How to use

1. Open the script's folder above.
2. Read its README.
3. Download the script and follow the steps there.
